# FORGE Desktop V3 — Blue Hour / 蓝调精密工作台

> V3 只替换视觉系统，复用 V2 已确认接近预期的总体布局与核心任务结构。V2 默认链接和样式保持不变，可随时对比。

## 设计意图

V2 的暖灰纸张色和编辑感带来了可读性，但整体偏旧、偏重，状态色也不够锐利。V3 改为更适合长时间使用的冷白工作面与蓝黑桌面壳层，强调精确、安静和实时性。

## 视觉系统

- **主背景**：冷白 `#F6F7FA`，避免暖灰发脏。
- **桌面壳层**：深海军蓝黑 `#090D16`，通过极细蓝色光晕建立层次，不做大面积渐变。
- **主动作**：皇家蓝 `#4169E1`；正在流转时使用更亮的 `#6E8BFF`。
- **通过**：青绿色 `#18A57C`；需要决策：珊瑚橙 `#EF704F`。
- **容器**：白色实体卡片 + 冷灰发丝线 + 低扩散阴影；减少灰色填充块。
- **字体**：Avenir Next / PingFang SC 作为主字体，DIN Alternate 用于数据，SFMono 用于事件。V3 不再使用大面积衬线标题。
- **动效**：活跃阶段仅保留路径光点、进度扫光和事件出现动画，避免装饰性脉冲泛滥。

## 与 V2 的差异

1. 更纯净的冷白画布与更深的壳层对比。
2. 标题改为清晰的无衬线体系，信息密度更像原生桌面工具。
3. 实时路径大盘改为深蓝玻璃仪表带，当前阶段具有连续光轨。
4. Artifact 卡片从纸片改为高精度白色面板，重要产出通过色条、边缘光和数据排版区分。
5. Inspector 改为冷灰独立工作面，日志区域使用真正的深色代码表面。
6. 圆角、边框、阴影和间距统一为 4/8/12/16/24 的桌面尺度。
