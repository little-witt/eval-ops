# 证据之火

这套视觉以“证据之火”为核心：复杂系统不被描绘成一件神秘的黑盒，而被拆成可观察、可连接、可回放的微小事件。视觉语言从工程控制台、实验记录和热处理工艺中取材，让每一条路径、每一个节点和每一次校验都像经过耐心锻造的金属纹理，清晰而有重量。

空间保持克制。深色石墨底承载大面积呼吸感，细网格提供隐形秩序；分叉的光路从左向右穿过画面，逐步由冷静的青色进入温暖的锻造琥珀，再在末端收束为可信赖的验证绿。信息不依靠长段文字解释，而通过路径、层级、密度和色彩的关系被看见。

形体采用半透明玻璃、金属边缘和微弱热晕的组合。节点不是装饰性的圆点，而是状态、证据和决策的视觉锚点；连接线有明确的起止、分叉和汇合，暗示从 Skill 到 Case、Trace、Diagnosis 再到 Candidate 的连续链路。重复的短刻度和细小标记像实验室的读数，赋予画面持续观测的节奏。

构图强调“可追溯的转化”：左侧保留安静的黑场，供标题和识别信息落位；中心的光路密度最高，表现评测、诊断与迭代发生的地方；右侧以单一明亮终点表示经过验证的 Champion。尺度对比要精确，主路径必须一眼可读，次级细节则在靠近观看时才显现。

最终作品必须呈现出顶级工具品牌的克制与手工感：每个间距、拐角、透明度和发光半径都经过反复校准，像由一位经验极深的系统设计师逐毫米打磨。文字只作为少量视觉锚点出现，绝不抢走图形本身的叙事；整体要像一张来自未来工程学档案馆、被精心保存的系统切片。
